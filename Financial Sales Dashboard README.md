# Interactive Financial & Sales Dashboard — Excel

An interactive Financial and Sales Analytics Dashboard built in Microsoft Excel as a hands-on data analytics learning project.

The project transforms transactional and financial data into interactive views covering income performance, geographical sales, and the sales process.

## 📊 Project Overview

The dashboard is designed to provide a consolidated view of business performance across multiple dimensions.

It contains three main analytical views:

1. Income Sources
2. Geographical Analysis
3. Sales Process

The dashboard supports year-wise filtering from 2020 to 2024, allowing users to explore how the key metrics change across different years.

## 🗂️ Dataset

## 📈 Dashboard Sections

### 1. Income Sources

The Income Sources dashboard provides an overview of financial performance.

Key metrics and analysis include:

- Total Income
- Income Target
- Income Achievement %
- Average Monthly Income
- Operating Profit
- B2B vs B2C contribution
- Income by source
- Income breakdown
- Monthly income trends
- Marketing-related income sources

Income sources include:

- Licensing
- Advertising
- Subscription
- Renting
- Usage Fees
- Asset Sale

The dashboard also provides deeper breakdowns such as:

- Floating License
- Software Metered License
- Renewal
- Premium
- Prime
- Equipment
- Lands
- Offices
- Facebook Page
- Google Ad
- Television Ad
- YouTube Channel

### 2. Geographical Analysis

The Geographical dashboard focuses on country-level sales performance.

It includes:

- Total Sales
- Country-wise sales
- Country-wise contribution %
- Actual vs Target
- Sales Achievement %
- Remaining %
- Tax analysis

Countries included in the analysis:

- Egypt
- USA
- Russia
- United Kingdom
- Canada
- Brazil

Tax metrics include:

- Payroll Taxes
- Property Taxes
- Excise Taxes
- Total Taxes

A world-map visualization is used to provide a geographical representation of sales performance.

### 3. Sales Process

The Sales Process dashboard visualizes different stages of the customer and order journey.

The analysis includes:

- Customers
- Branches
- Website
- Payment Methods
- Credit Card
- Cash on Delivery
- Registered Customer Information
- Non-Registered Customer Information
- Paid Orders
- Delivery Types
- Shipment
- Download
- Sale Status
- Refunded Orders

This view helps visualize the relationship between different stages of the sales process.
