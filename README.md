# Excel Learning Journey 📊

This repository contains my Excel practice work from Week 1 of my learning journey.

## 🚀 What I did

- Practiced Basic Functions & Logical Formulas (IF, SUMIF, COUNTIF, AND, OR)
- Worked on Date & Time Functions (TODAY, DATEDIF, WORKDAY, NETWORKDAYS)
- Learned Lookup Functions (VLOOKUP, HLOOKUP, INDEX + MATCH)
- Performed Sorting & Data Handling (Custom Sort, Freeze Panes, Data from other sheets)
- Practiced Text Functions (LEN, LEFT, RIGHT, MID, TRIM, CONCAT, SUBSTITUTE, REPLACE)
- Worked on data cleaning and formatting using real-like datasets

## ⚠️ Problems I faced

- Confusion in SUMIFS / AVERAGEIFS (range vs criteria)
- When to use INDEX + MATCH instead of VLOOKUP
- Missing XLOOKUP in my Excel version
- Handling text cleaning (extra spaces, case issues)
- Managing structured datasets across multiple sheets

## 🛠 How I solved them

- Broke problems into smaller steps  
- Focused on understanding logic instead of memorizing formulas  
- Practiced on datasets instead of just theory  
- Compared different approaches to solve the same problem
