# Excel Learning Journey 📊  

This repository contains my Excel practice work from Week 1 of my learning journey.  
The goal is to build a strong foundation in Excel by practicing real-like datasets and solving practical problems.

---

## 🚀 What I did  

- Practiced Basic Functions & Logical Formulas  
  (IF, SUMIF, COUNTIF, AND, OR)  

- Worked on Date & Time Functions  
  (TODAY, DATEDIF, WORKDAY, NETWORKDAYS, etc.)  

- Learned Lookup Functions  
  (VLOOKUP, HLOOKUP, INDEX + MATCH)  

- Solved multiple dataset-based questions  
  (count, sum, average, conditional logic)  

- Performed Sorting & Data Handling  
  (Custom Sort, working across sheets, data extraction)  

- Practiced Text Functions  
  (LEN, LEFT, RIGHT, MID, TRIM, CONCAT, SUBSTITUTE, REPLACE)  

- Worked with Find & Search + Wildcards  
  (*, ?)  

- Applied basic data cleaning techniques  
  (removing spaces, fixing formats, standardizing values)  

- Practiced on real-like datasets to understand practical usage  

---

## ⚠️ Problems I faced  

- Confusion in SUMIFS / AVERAGEIFS  
  (range vs criteria)  

- When to use INDEX + MATCH vs VLOOKUP  

- XLOOKUP not available in my Excel version  

- Handling text cleaning issues  
  (extra spaces, casing problems)  

- Managing structured datasets across multiple sheets  

---

## 🛠️ How I solved them  

- Broke problems into smaller steps  

- Focused on understanding the logic behind formulas  

- Practiced on datasets instead of just theory  

- Compared different approaches for the same problem  

- Repeated practice until concepts became clear
